What this does not catch

Shape validation is one control, not the whole safety story. Stated up front so nobody buys it as more than it is.

  • Prompt injection inside a valid field. A summary that reads "ignore previous instructions" is still a well-shaped string. It passes here and needs a separate control before it reaches anything that acts on text.
  • A confidently wrong category. If the model calls a billing complaint "sales", the allowlist has no opinion. That is a scoring and evaluation problem, handled with a held-out set, not a validator.
  • The LLM being unreachable. Handled, but by a different branch: three retries, then the same human queue rather than a silent failure.
